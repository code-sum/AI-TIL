### [ICLR 2025] SCoRe: Training Language Models to Self-Correct via Reinforcement Learning [🗂️](https://arxiv.org/abs/2409.12917)

- 3줄 요약
  - dd

- Motivation
  - There are many attempts to solve math and coding problems using LLM models
  - However, for various problems, LLM does not always present only the correct answers
  - Generally, to train the model, the correct answer is directly informed or seperate model is used to give feedback
  - However, what we want is not just to find answer, but LLM's ability to detect and fix mistakes or errors on its own
 
- Problem
  - When LLM is asked to correct its own mistakes, the model rarely corrects the answers, or turns the answers into incorrect ones
  - In addition, if you are forced to learn the correct answer, LLM will only learn how to guess the correct answer, not the "correction process."
  - LLM needs to use its data to diagnose and correct errors through intrinsic self-correction

- Background
  - SFT (Supervised Fine Tuning)
    - Get modifications directly from a larger model or with human
    - Problem: Calibration training is impossible without external help, costs ans time, and requires seperate system design in deployment
  - STaR (Self-Taught Reasoner)
    - A technique that generates an inference process on its own and repeatedly learns the model again by selecting only the correct data
    - SFT-based approaches
    - Problem: The model does not learn how to fix it from the result of the first attempt, but only learns "Let's get the answer right on the second attempt"

- SCoRe
  - Resolve two causes that the existing SFT/STaR method failed to self-correction
    - Distribution Mismatch
    - Behavior Collapse
  - Methodology
    - Stage 1: Fix the first attempt to separate the role between attempts
    - Stage 2: Learn how to improve your answers with Reward Shaping
  - Performance Verification
    - MATH: 15.6% increase in self-correction capacity over base model
