- Introduction
  - MoE (Mixture-of-Experts) LLMs have demonstrated impressive performance across diverse tasks
    - Activates only a subset of experts within each FFN layer
    - Significantly reduces compute demands
  - MoE
    - Experts: subset of specialized subnetworks at each layer for each token
    - Dense FFN is replaced with a large pool of expert networks
    - A learned gating mechanism dynamically selects the most relevant experts to process each token

- KTransformers: a system that enables efficient local inference for large MoE models on hybrid CPU/GPU platforms
  - Proposed Techniques:
    - AMX-optimized kernels
    - CPU-GPU coordination
    - Expert Deferral strategy
