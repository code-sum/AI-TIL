### [OSDI 2025] NEUTRINO: Fine-grained GPU Kernel Profiling via Programmable Probing [🗂️](https://www.usenix.org/conference/osdi25/presentation/huang-songlin)

- 3줄 요약
  - 스케일링 법칙(scaling laws) 시대에 GPU의 중요성이 커지며 미세한 GPU runtime behavior를 파악하는 일이 매우 중요해졌지만, 기존 GPU kernel profiler들은 대개 kernel-exclusive하거나 hardware-dependent하여 정밀한 측정을 수행하기 어려움
  - 본 논문은 assembly-layer probing을 활용해 하드웨어 독립적이면서도 시간 및 값 도메인 전반의 프로파일링 유연성과 instruction-level의 미세한 측정 입도를 확보한 프로그래머블 인터페이스인 NEUTRINO를 제안
  - 아울러 NEUTRINO가 수집한 상세 정보를 효과적으로 시각화하는 Densified Memory Access Timeline(DMAT)을 도입하고 Linux 환경의 NVIDIA 및 AMD GPU 상에서 구현 및 평가를 진행하여, 본 시스템이 낮은 오버헤드로 탁월한 GPU kernel profiling 성능을 제공함을 입증

- Limits of Existing GPU Profiling
  - Unlike CPUs, GPUs lack:
    - Time interrupts
    - Locks
    - Efficient CPU-style profiling hooks
  - GPU kernels appear atomic to the host OS 
  - Massive SIMT parallelism and fast-evolving features make profiling even harder
  - Kernal-exclusive profilers
    - observe only kernel-level behavior
    - expose only coarse-grained metrics (e.g., FLOP/s)
  - Hardware-dependent profilers
    - rely on PM counters and vendor-specific features are typically sampling-based
  - Instrumentation-based approaches
    - NVBit: proprietary ISA / binary manipulation
    - HIPAnalyzer: compiler-based instrumentation
    - still target only specific statistics (e.g., mem access divergence, reuse distance)
  - Unlike CPUs, GPUs still lack a programmable, general-purpose fine-grained profiling interface
