### [ICML 2025] Not All Tokens Matter All The Time: Dynamic Token Aggregation Towards Efficient Detection Transformers [🗂️](https://dl.acm.org/doi/10.5555/3780338.3780728)

- 3줄 요약
  - DETR(Detection Transformer)의 막대한 연산량은 자원 제약 환경 배포의 걸림돌이며 특히 encoder가 주요 병목으로 꼽히지만, 기존 static sparsification 방식은 토큰의 다양한 중요도를 반영하지 못해 성능 저하를 초래
  - 이에 본 논문은 토큰 밀도를 조절하고 multilevel token sparsification을 수행하는 Dynamic DETR을 제안하며, 저레벨 토큰에는 proximal aggregation을, 고레벨 토큰에는 holistic strategy를 적용해 공간적 온전성과 문맥 정보를 모두 확보
  - 나아가 representation consistency를 유지하고 객체 패턴을 보존하는 center-distance regularization을 도입해, 다양한 canonical DETR 모델에서 기존 방식을 뛰어넘는 성능과 광범위한 범용성을 입증

- Background
  - Object Detection
    - Conventional detectors: pre-defined anchores, IoU-based matching, many-to-one > multi-scale / multi-ratio detection, but duplicate predictions > NMS
      - Input image > Pre-defined anchors > Object detector > Predicted bboxes > [NMS] > Post-processed bboxes
    - DETR: no hand-crafted anchors, direct set prediction, one-to-one > no redundant predictions > no NMS
      - Input image > DETR > Predicted bboxes
  - DETR
    - CNN Backbone: Extract a 2D feature map from the input image (e.g., ResNet outputs 25x34x2048), then reduces channels via 1x1 conv.
    - Encoder: Flattens the feature map into a token sequence, adds positional encoding, and applies self-attention so every token captures global context across the entire image
    - Decoder: Takes N learnable object queries and performs cross-attention to the encoder output. Each query learns to attend to a specific object region, iteratively refined over multiple layers
    - Prediction Head: An FFN on each query output predicts a class label and bounding box. The N predictions are matched 1:1 ground truth via Hungarian algorithm - no anchors, no NMS
