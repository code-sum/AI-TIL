### [ACL 2025] Mixtures of In-Context Learners [🗂️](https://aclanthology.org/2025.acl-long.1277/)

- 3줄 요약
  - dd

- 연구배경
  - LLM
    - 대규모 텍스트 데이터를 활용하여 학습한 거대한 언어 모델. 문맥을 이해하고 이를 기반으로 텍스트를 생성하는 AI의 핵심 요소
      - 다양한 자연어 작업(번역, 요약, 질의응답 등)에 범용될 수 있음
  - MoE (Mixture of Experts)
    - 여러 개의 전문가 모델 중 일부만 선택적으로 활성화해 연산 효율을 높이는 구조
      - LLM 의 모든 부분을 사용하지 않고 입력에 따라 모델의 일부분을 활성화
  - In-Context Learning
    - LLM 의 파라미터를 수정하지 않고, 입력 프롬프트 내의 예시만으로 새로운 작업에 적용하도록 하는 프롬프트 기법
      - 학습된 기존 지식을 활용하여 추가 학습 없이 새로운 Task 에 적용할 수 있도록 한다
