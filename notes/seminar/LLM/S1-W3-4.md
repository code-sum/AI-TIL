### [ACL 2024] Don’t Hallucinate, Abstain: Identifying LLM Knowledge Gaps via Multi-LLM Collaboration [🗂️](https://aclanthology.org/2024.acl-long.786.pdf)

- 3줄 요약
  - dd

- Knowledge Gap?
  - Information is missing or outdated or unreliable
    - but LLM is still "speaking with confidence"
    - Hallucination, Bias

- Previous works
  - Token Probability: Use token probabilities with an optimal threshold (turned on a held-out set) to decide when to abstain
  - Temperature Scaling: softmax() > Token Probability
  - Ask for Calibration: Prompting with "Provide the probability that your guess is correct"
  - would require a held-out set for training and hyperparameter tuning > potentially harming generalization across knowledge domains
  - Assume a single LLM can reliably self-reflect, but this assumption is doubtful under hallucination and bias

- Multi-LLM Collaboration - Cooperate
  - Self
    - LLM generates proposed answer
    - Domain experts (same LLM, Prompt) generate a knowledge passage about q
    - Domain experts generate domain-specific feedback
    - LLM judges abstain
  - Others
    - LLM generates proposed answer
    - Other LLMs generate feedback
    - LLM judges abstain

- Evaluation
  - R-Acc (Reliable Accuracy): out of all questions answered, how many are correct?
  - A-Acc (Abstain Accuracy): whether the abstain decisions are correct
  - COMPETE emphasizes reliability and greatly avoids wrong answers

- Analysis - Retrieval
  - Proposed: 2-step abstain-based framework
    - (1) QA without retrieval
    - (2) If the LLM abstains, request retrieval and re-check
    - (3) If the LLM still decides to abstain, it indicates that the retrieval has failed to find relevant documents

- Comments
  - Three key takeaways
    - Organization
    - Multi-LLM methodology
    - Simple idea, but validates across multiple scenarios
